# Win32Emu.Tools.ApiStatusGenerator

A tool that exports API status metadata generated by source generators to JSON file for use in GitHub Pages documentation.

## Purpose

This tool exports the Win32 module API implementation status that is automatically generated at compile-time by the `ApiStatusGenerator` source generator. The metadata includes:
- List of all Win32 DLL modules
- All exported functions in each module
- Implementation status (implemented vs stub)
- Metadata (ordinal, version, export name, etc.)

The generated JSON is consumed by the GitHub Pages site to display API coverage status.

## How It Works

Unlike traditional parsing tools, this leverages C# source generators to extract API metadata at compile-time:

1. **Compile-Time Generation**: The `ApiStatusGenerator` source generator (in `Win32Emu.Generators`) scans all methods with `[DllModuleExport]` attributes during compilation
2. **Metadata Extraction**: The generator extracts all metadata (ordinal, version, stub status, etc.) using Roslyn's semantic model
3. **Code Generation**: Generates a static `ApiStatusMetadata` class containing JSON data
4. **Export Tool**: This tool simply reads the generated metadata and writes it to a file

## Advantages Over Regex Parsing

- ✅ **Type-Safe**: Uses Roslyn's semantic model instead of regex
- ✅ **Accurate**: No false positives/negatives from regex patterns
- ✅ **Maintainable**: Changes to attribute format automatically reflected
- ✅ **Fast**: Metadata generated once at compile-time
- ✅ **Reliable**: Uses the same compiler infrastructure as the build

## Usage

```bash
dotnet run --project Win32Emu.Tools.ApiStatusGenerator <output-json>
```

Example:
```bash
dotnet run --project Win32Emu.Tools.ApiStatusGenerator docs/pages/api-status.json
```

Note: The tool requires Win32Emu to be built first, as it accesses the generated metadata.

## Output Format

The tool generates a JSON file with this structure:

```json
{
  "generatedAt": "2025-11-13T23:37:40.771Z",
  "modules": [
    {
      "name": "KERNEL32.DLL",
      "className": "Kernel32Module",
      "functions": [
        {
          "name": "GetVersion",
          "isStub": false,
          "ordinal": 42,
          "version": null,
          "exportName": null,
          "forwardedTo": null
        }
      ]
    }
  ]
}
```

## Integration

This tool is designed to be run:
- Manually by developers when updating documentation
- Automatically via GitHub Actions on push to main branch
- Before deploying GitHub Pages site

The generated JSON is consumed by the GitHub Pages web interface to display API implementation status.

## Technical Details

### Source Generator

The `ApiStatusGenerator` source generator:
- Runs during Win32Emu compilation
- Uses `IIncrementalGenerator` for efficient generation
- Processes all methods with `[DllModuleExport]` attributes
- Extracts metadata using Roslyn's `IMethodSymbol` API
- Generates a `ApiStatusMetadata` static class with JSON data

### Export Tool

This command-line tool:
- References Win32Emu project to access generated metadata
- Reads `Win32Emu.Win32.ApiStatusMetadata.Json` property
- Writes to specified output file
- Displays statistics for verification
